FMI vs Azimuth — Flight Inspection Strip
FMI OK
FMI = Δf / f_rot = 480 Hz / 30 Hz = 16.000 nominal. ICAO Annex 10 tolerance: 15.000 – 17.000 (red dashed lines). A dip below 15 at any azimuth = that bearing is out-of-tolerance at the aircraft. Orange dashed = reference FMI from m₀.
Signal Phase vs Azimuth
Phase OK
What it shows: The bearing error introduced by antenna/obstruction errors — expressed as a phase error in degrees. For a perfect array this is a flat line at 0°. This is NOT the raw atan2 of the array factor — it is the correct Doppler model: phase_err(θ) = (1/N) Σ k·Δrₙ·cos(θ − φₙ). ICAO: ≤ ±1° site acceptance.
Bearing Error vs Azimuth
Brg OK
Bearing error = phase error converted to degrees (same data, clearer scale). Green band ±1° = ICAO site acceptance. Amber ±0.5° = preferred. Red ±2° = CAT I absolute limit. Perfect array = zero line. Antenna ΔR = sinusoidal, Δφ = spike at that antenna's azimuth.

9960 Hz FM Subcarrier — Detail
The FM subcarrier whose instantaneous frequency swings between 9480 Hz and 10440 Hz (±480 Hz at 30 Hz rate). The phase of this FM at the 30 Hz reference zero-crossing encodes the receiver azimuth.
VAR − REF Phase Difference = Encoded Bearing
The aircraft VOR receiver extracts this phase difference. Ideal: a flat line equal to the receiver azimuth (°). Wobble or drift = bearing error. Obstruction causes a periodic dip at the affected azimuth.
Doppler Phase Error Sweep — Array Rotates 0° → 360°
Per-azimuth bearing error plotted as the electronic rotation sweeps the full circle. For a perfect array: flat at 0°. Each antenna error creates a sinusoidal ripple at its azimuth. Obstruction creates a localised dip. This is what a flight inspection recorder captures.
RF Spectrum — Full 0–20 kHz (Hanning FFT)
Frequency content of the DVOR signal at the receiver. Key lines: 30 Hz (AM reference), 9960 Hz (FM subcarrier centre), 9480 & 10440 Hz (FM sidebands at ±480 Hz). Antenna errors or obstruction raise the inter-modulation floor and cause sideband asymmetry.
9960 Hz Subcarrier — Sideband Zoom (±2 kHz)
Zoomed view of the FM subcarrier region. Sidebands at 9480 Hz and 10440 Hz should be equal in amplitude. Asymmetry = array or modulator fault. The carrier-to-sideband ratio is set by Bessel J₁(Δf/f_sub).
Low-Frequency Spectrum — 30 Hz Reference Zone
Zoomed to 0–500 Hz. The 30 Hz AM reference should be the dominant feature; its level is proportional to m₀. Harmonics at 60/90 Hz indicate modulator distortion — a real fault visible on a spectrum analyser during maintenance.
